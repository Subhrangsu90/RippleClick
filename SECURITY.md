# Security Policy

## Supported Versions

Security fixes are handled on the latest released version of RippleClick.

## Reporting a Vulnerability

Please do not open a public issue for suspected security problems.

Report privately to the project maintainers with:

- A clear description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix, if you have one

Maintainers should acknowledge the report, investigate, and coordinate a fix before public disclosure.

## Scope

RippleClick uses a local Electron app, transparent overlay windows, global shortcuts, and Windows hook helpers. Reports related to privilege boundaries, unsafe IPC, arbitrary command execution, dependency compromise, or unexpected data exposure are especially important.
